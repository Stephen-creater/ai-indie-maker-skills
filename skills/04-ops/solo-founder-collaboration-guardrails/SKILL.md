# Solo Founder Collaboration Guardrails

Use this skill when someone wants to build with a friend, split equity/revenue, or divide product/development/marketing work.

## Core Principle

Early founder work is rarely cleanly divided. If one person says “I do marketing” but has no channel, audience, budget, or sales track record, a 50/50 split is usually risky.

## Evaluate Contributions

Check:

- existing audience or channel
- product/development execution
- domain expertise
- capital or ad budget
- sales/customer access
- operations/support ownership
- time commitment
- maintenance after launch
- legal/IP ownership

## Recommended Path

1. Start with a short project, ideally 2 to 4 weeks.
2. Define one concrete deliverable and one measurable channel outcome.
3. Track time, decisions, assets, cost, and revenue.
4. Decide whether to continue after evidence, not friendship.
5. If continuing, write split terms, vesting/exit, IP ownership, support duties, and revenue rules.

## Red Flags

- “五五分” before proving contribution.
- No one owns customer support.
- Marketing person has no audience and no channel plan.
- Developer owns all implementation and all support but split is equal.
- The project is long-term before a short collaboration test.
- No rule for what happens if one person stops working.
