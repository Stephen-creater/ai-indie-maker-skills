# Niche SaaS Opportunity Miner

Use this skill when the user has a domain, hobby, job workflow, or software ecosystem and wants to find small but monetizable product opportunities.

## Core Principle

Niche SaaS works when a small group has a repeated painful task, existing tools are awkward, and the builder can add domain context that generic AI or generic SaaS cannot.

## Discovery Prompts

Ask or infer:

- What tool or ecosystem does the user know deeply? Examples: Notion, Gmail, cloud ops, video editing, spreadsheets, real estate design.
- What repeated task feels annoying, manual, or hidden inside many clicks?
- Who has money and urgency: individual prosumer, agency, local business, enterprise operator, creator, student, job seeker?
- What existing products are close but ugly, overpriced, too broad, or missing a workflow?
- What content/community already shows demand?

## Mining Patterns

- **Tool extension**: Gmail plugin, Notion sync, browser extension, cloud console helper.
- **Workflow compression**: turn many steps into one action, one form, one import/export, one batch operation.
- **Template/library marketplace**: paid patterns, course unlocks, prompts, visual assets, domain templates.
- **Vertical AI shell**: one AI capability packaged for a specific context, such as real estate rendering, job-search resumes, classroom materials, or creator captions.
- **Better UI for proven ideas**: rebuild a known need with cleaner UX, clearer onboarding, and stronger landing page.

## Validation Checks

- Can the pain be demonstrated in under 60 seconds?
- Does the user repeat it weekly or daily?
- Would a user pay before the tool is perfect?
- Is the buyer reachable through a specific channel?
- Is there a credible wedge feature that can be built fast?
