# Repository Guide

This repository packages distilled skills for AI-assisted overseas indie product building.

## Scope

- Keep the public repo focused on reusable skills and compact supporting docs.
- Raw transcript and PPT screenshots are included under `source/` because the repository owner explicitly requested full traceability.
- Do not add private materials outside `source/` without an explicit request.

## Skill Authoring Rules

- Each skill lives in `skills/<category>/<skill-name>/SKILL.md`.
- Keep each `SKILL.md` self-contained and concise.
- Use clear trigger descriptions in YAML frontmatter.
- Prefer workflow checklists, decision rules, output formats, and concrete examples over broad essays.
- Avoid pretending unverified product names or revenue claims are confirmed facts.

## Source Caveats

Some product/tool names in the transcript were noisy speech-to-text outputs. In public-facing skills, use normalized names only when obvious, and mark uncertain examples as examples rather than verified facts.
